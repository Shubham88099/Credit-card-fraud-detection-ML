# 💳 Credit Card Fraud Detection

This project helps identify **fraudulent credit card transactions** using **machine learning**.  
In real-world financial data, fraudulent cases are extremely rare compared to normal transactions — this makes the dataset **highly imbalanced**.  
To address this, the project applies resampling techniques and trains a model to accurately detect fraud.

---

## 🔍 Project Overview

The main goal of this project is to build a model that can classify transactions as **normal** or **fraudulent**.

### Steps Involved:
1. **Data Exploration** – Understand the dataset and identify imbalances.  
2. **Data Preprocessing** – Clean and prepare the data for modeling.  
3. **Resampling** – Use **undersampling** to balance normal and fraudulent transactions.  
4. **Model Training** – Train a machine learning model to detect fraud.  
5. **Model Evaluation** – Evaluate the performance using metrics like accuracy, precision, recall, and F1-score.
